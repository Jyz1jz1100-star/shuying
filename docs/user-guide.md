# 述影使用指南

[返回项目首页](../README.md)

## 第一次打开

从[发布页](https://github.com/Jyz1jz1100-star/shuying/releases/tag/v2.0.0-alpha.3)下载 `Shuying-windows-x64.zip`，完整解压后运行 `VideoSummarizer.exe`。`Source code` 是开发用源码，不是可直接打开的应用。测试包尚未签名。

先点击“先体验示例”，熟悉阅读、搜索、修改和导出。这个示例不需要模型、密钥、显卡或网络服务。

## 导入自己的内容

- **已有字幕：** 导入 UTF-8 编码的 SRT / VTT，可直接阅读和编辑。也可以使用其他转写工具导出的字幕。
- **本地视频或音频：** 选择文件，使用默认的“阅读 / 转写字幕”模式，先得到文字。
- **公开视频：** 粘贴支持站点的链接。应用优先读取人工字幕，没有时再转写声音。站点限制或变更可能导致读取失败。

媒体限制为单个文件 2GB、时长 2 小时；字幕最大 10MB。暂不支持登录、付费、DRM 内容、直播和播放列表，也不识别画面、幻灯片和板书。

## 转写需要准备什么？

没有现成字幕时，需要语音识别模型。首次按需下载，均衡模型约 1.5GB，高精度模型约 2.9GB，请预留磁盘空间和下载时间。

兼容 Vulkan 的显卡和驱动可以加速转写，也可以明确选择 CPU。CPU 通常明显更慢；目前尚未完成无 Vulkan 驱动机器的独立验证。导入字幕和体验示例不需要这些条件。

## 可选：用 AI 整理成笔记

“全文转写”保留文字和时间点；“AI 总结”提炼核心结论和重点；“思维导图”独立提取主题、概念分支和短关键词。三者共用转写，只阅读、修改、导出字幕时，不需要调用 AI 总结模型。

在模型设置中选择一种方式：

| 方式 | 如何准备 | 内容去向 |
| --- | --- | --- |
| 本机模型 | 安装并启动 [Ollama](https://ollama.com/)，选择已有模型，或输入模型的完整名称 | 在本机处理 |
| 在线服务 | 填写兼容 OpenAI Chat Completions 的服务地址、模型 ID 和密钥 | 所需文本发送给所选服务商，可能产生费用 |

本机模型的初始默认名称为 `qwen3.5:9b-q4_K_M`，可以改成适合自己电脑的模型。保存名称不会下载；生成总结和导图时，缺少的模型会按需下载。模型越大，对内存和显存的要求通常越高。

在线服务的远程地址须使用 HTTPS，接口格式为 `/v1/chat/completions`。应用不会把视频或音频发送给该 AI 服务；字幕和整理所需的文本会发送。密钥使用 Windows DPAPI 加密保存。

## 核对、修改与继续处理

在字幕中搜索内容，可以直接修改识别错误。原始文字会保留；校对建议中的数字、否定词和部分技术词变化会被标记，方便重点检查。

点击总结或导图的引用可查看对应字幕及时间。有保留的本地音频时，可以回听；只有站点字幕、未下载音频时，通过文字和来源链接核对。引用是查找入口，不能保证 AI 内容正确。

修改文字或术语后，用“更新总结和导图”重新生成。失效的总结和导图不再作为当前结果展示。失败或取消后，可以继续处理，复用输入未变化的已完成部分。旧任务需主动补生成，不会自动产生模型费用，也无需重新转写。

## 导出到其他工具

在“全文转写 / AI 总结 / 思维导图”之间切换。导图使用带彩色连线的可视化画布，按中心主题、概念分支和关键词展开。可拖动画布、滚轮或双指缩放、点击圆点折叠分支；手机可切换大画布。点击有引用的节点文字可定位原文；“导出导图大纲”保存相同的主题树为 Markdown 文件。导图由 AI 独立生成，不会把整段转写或总结当成节点。尚未生成或原文已修改时会明确提示。

选中字幕后，支持的 YouTube / Bilibili 来源会显示“在原视频打开”时间链接。字幕阅读稿的 Word / Markdown 导出也保留这些链接。其他站点或本地文件不生成无法保证有效的网页时间链接；有本地回听音频时仍可定位音频。在线链接的实际跳转行为取决于站点播放器。

| 格式 | 导出的内容 |
| --- | --- |
| Word / Markdown | 生成后导出摘要及来源引用；未生成时导出完整字幕文字稿，旧任务保留历史讲义 |
| TXT | 当前字幕文字 |
| SRT / VTT | 当前字幕及时间，供播放器和字幕工具使用 |
| JSON | 供进一步处理的结构化数据 |

## 文件保存在哪里？

在“你的材料”中，可以搜索标题、文件名、作者和链接，并结合处理状态、材料来源筛选。搜索范围包括较早的任务，列表每次展示 50 份，可继续显示更多。这里只整理显示方式，不自动移动或重命名原文件。

任务数据默认保存在 `%LOCALAPPDATA%\VideoSummarizer`。本地处理不会向 AI 云服务发送内容，但视频和模型下载仍需要网络。

媒体副本默认保留。“清理媒体副本”只删除应用保存的副本，不删除你原来选择的外部文件，字幕和讲义继续保留。清理后再回听，需要重新导入或下载媒体。

## 遇到问题

确认使用的是 Windows x64，并且完整解压了发布包。下载或转写失败时，先尝试内置示例或已有字幕，确认阅读与导出是否正常；再检查网络、模型下载和所选设备。

需要帮助时，请[提交问题](https://github.com/Jyz1jz1100-star/shuying/issues)，附上应用版本、操作步骤、硬件和脱敏后的错误信息。请勿上传密钥、私人媒体、完整日志或任务数据库。
