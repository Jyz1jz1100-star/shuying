# OSS support application working notes

Update with verifiable links and figures before submission; this is not a claim of established adoption.

Shuying is a Windows local-first tool for turning Chinese and mixed Chinese/English technical videos into reviewable documents. It preserves original transcripts, links paragraphs to source segments, records corrections and resumes completed processing blocks. Intended community use: readable documentation from open-source tutorials and technical talks.

Collect public releases, reproducible evaluations, external installation reports, community cases with permission, actual downloads and issue/PR maintenance history. Never invent counts.

Proposed support usage: Codex for issue reproduction, regression tests, code review and Windows releases; API credits for maintenance automation such as failure analysis and draft release notes, with human review. Product inference remains user-configured.
