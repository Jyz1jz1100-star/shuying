# 述影 Shuying

**把视频和录音，变成可读的文字、抓得住的重点和看得清的思维导图。**

课程、访谈、播客、会议录音，听过之后也能方便地回顾。导入文件或粘贴视频链接，述影帮你转成文字；再按需生成 AI 总结和导图，点击引用回到原文核对，最后导出到自己常用的工具。

## 一份材料，三种读法

| 结果 | 适合做什么 | 你会看到什么 |
| --- | --- | --- |
| **全文转写** | 找原话、整理录音、修改字幕 | 带时间点的完整文字，可搜索和校订 |
| **AI 总结** | 快速了解内容、复习重点 | 提炼后的核心结论与少量关键要点 |
| **思维导图** | 梳理概念、看清内容关系 | 主题节点和彩色分支连线，可缩放、拖动和折叠 |

总结和导图分别生成，共用已有转写。先转成文字，之后再补生成，不必重新处理音视频。导图中的关键词和总结中的引用都可以回查对应原文。

## 什么时候用得上？

- **学完一节课：** 用总结复习重点，用导图梳理知识关系，遇到不明白的地方回看原文。
- **听完访谈或播客：** 搜索那句想找的话，查看时间点；有本地音频时可以回听，支持的 B站 / YouTube 来源可跳转播放位置。
- **整理自己的录音：** 转成文字、修正识别错误，再导出 Word 或 Markdown。
- **处理已有字幕：** 直接导入 SRT / VTT，搜索、修改和导出，无需配置总结模型。

## 在电脑或手机上使用

### Windows 桌面版

1. 下载并完整解压 ZIP，打开 `VideoSummarizer.exe`，保留同目录的其他文件。安装包无需另装 Python 或 Node.js，目前尚未签名。
2. 点击“先体验示例”，直接试试阅读、搜索、校订和导出，无需模型或密钥。
3. 导入自己的视频、音频、字幕，或粘贴支持的视频链接。需要 AI 整理时再配置模型；Alpha.3 中称为“讲义”，当前源码版为“总结和导图”。

音视频转写首次使用会下载语音识别模型。当前源码版的新建文件和链接任务默认使用 GPU 与高精度模式，也可手动选择均衡模式或 CPU。已有字幕不需要语音识别。更多说明见[使用指南](docs/user-guide.md)。

### 手机浏览器

服务部署好后，用手机打开管理员提供的 HTTPS 地址，输入访问密钥，粘贴 B站 / YouTube 链接或上传文件即可。模型和处理任务运行在服务电脑上，手机不需要安装模型。

手机页面与桌面本体共用总结和导图生成能力。导图可切换大画布；任务失败或取消后，已保存的转写仍可读取和导出。

这需要单独[部署 API 服务](docs/service.md)，并保持服务电脑联网、登录且不休眠；Alpha.3 桌面安装包不包含服务安装器。它也可供其他应用接入，见 [API 接入指南](docs/api.md)。

## 结果带得走

| 格式 | 内容 |
| --- | --- |
| Word / Markdown | AI 文稿与引用；未生成 AI 内容时导出完整转写 |
| TXT | 转写文字 |
| SRT / VTT | 带时间的字幕，供播放器或剪辑工具使用 |
| 导图大纲（Markdown） | 按主题和关键词组织的层级结构 |
| JSON | 用于其他工具的结构化数据 |

修改原文或术语后，可以重新生成总结与导图。原始文字保留，输入未变化的已完成步骤可以复用。

## 使用前了解这些

**内容存在哪里？** 桌面版保存在本机，手机使用时保存在服务电脑。选择本地模型，整理过程不向 AI 云服务发送内容；选择在线 AI 服务，会发送所需文字，不发送音视频。视频与模型下载仍需联网，在线服务可能另行收费。

**支持多大的材料？** 桌面版单个媒体最长 2 小时、最大 2GB，UTF-8 字幕最大 10MB。API 有独立限制，以手机页面提示和管理员配置为准。

**能处理任何视频吗？** 目前处理语音和字幕，不识别画面、幻灯片或板书。公开视频的可用性取决于来源站点；登录、付费、DRM 内容、直播和合集批量导入暂不支持。AI 结果可能出错，引用方便核对，不代表内容已验证。

**必须用在线 AI 吗？** 不需要。阅读和编辑已有字幕不需要总结模型；总结与导图可以使用本机 Ollama，也可以连接兼容的在线服务。目前界面和 AI 整理内容以中文为主。
